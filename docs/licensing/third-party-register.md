It also found a signed integer overflow in the WAV MS-ADPCM decoder (line 83182; arithmetic only). Both are to be reported upstream. In October 2026 CI fuzzing found an **out-of-bounds read** in FLAC seeking: after a frame whose header was read but not decoded, seeking back "within" that frame read outside the decoded-samples buffer. OpenTalk patches this (the patch adds a check that the current frame was decoded before its samples are read or seeked within; 38 lines, kept as `opentalk-flac-seek.patch`, regression test in `tst_media_file`) until upstream fixes it; to be reported upstream. The Windows package also contains `THIRD-PARTY-NOTICES.txt`, which lists every component above with its licence; CI fails if the package contains a DLL the notices do not cover. No third-party fonts or icons are bundled. The application icon is OpenTalk's own, drawn by `tools/icon/make_icon.py` (GPL-3.0-only). The built-in event sounds are generated by OpenTalk's own code (`src/audio/Sounds.cpp`) and are GPL-3.0-only like the rest of the project; no TeamTalk sounds are used.
