OpenTalk is an open-source, self-hosted voice and text chat for groups, built to work fully with the keyboard and a screen reader. This is the **first release candidate** of version 1.0: every feature of the original plan is in it and tested automatically, but it has **not yet been tried with NVDA or with real microphones and speakers**. Please try it and report what you find.

## Downloads

| File | What it is |
|---|---|
| `OpenTalk-1.0.0-rc.1-portable-windows-x64.zip` | **Portable edition.** Extract it anywhere (a folder or a USB drive) and run `OpenTalk.exe`. Settings and logs stay in that folder. Nothing is installed. |
| `OpenTalk-1.0.0-rc.1-setup-x64.exe` | Installer for the current Windows user. No administrator rights needed. Uninstalling keeps your settings. |
| `SHA256SUMS.txt` | Checksums of both files. |

Both contain the desktop app, the server (`opentalk-server.exe`), the reachability checker (`opentalk-ping.exe`), the audio benchmark, the example bot and two example plugins.

**Needs:** Windows 10 (version 1809 or later) or Windows 11, 64-bit. For a Linux server, use the container image or build from source ([hosting guide](https://github.com/donovanmalisch23-alt/opentalk/blob/v1.0.0-rc.1/docs/server-administration/hosting.md)).

### Windows will warn that the files are unsigned

The files are not code-signed yet, so Windows SmartScreen says "Windows protected your PC". Choose "More info", then "Run anyway". To check that a download is genuine first:

- In PowerShell, `Get-FileHash OpenTalk-1.0.0-rc.1-portable-windows-x64.zip` must show the same SHA-256 as `SHA256SUMS.txt`.
- With the GitHub command-line tool, `gh attestation verify <file> --repo donovanmalisch23-alt/opentalk` shows that the project's own CI built the file from this release's commit.

## Getting started

1. Run `OpenTalk.exe`. To host, choose Server, "Host a server on this computer"; to join someone else's, Server, Connect (Ctrl+O).
2. Read the [getting started guide](https://github.com/donovanmalisch23-alt/opentalk/blob/v1.0.0-rc.1/docs/user-guide/getting-started.md). Every menu shows its shortcuts.
3. If something goes wrong, Help, "Create a support file" collects what is needed for a report.

## What is in it

- **Text chat:** accounts and guests, channels (temporary and persistent, passwords, user limits), channel, private and server-wide messages, status messages, and automatic reconnection.
- **Voice:** push-to-talk with a global key, voice activation or always-on; Opus with error correction and an adaptive jitter buffer; voice encrypted over UDP with automatic fallback to the main connection; noise suppression, automatic gain, echo cancellation and voice effects; event sounds and soundpacks.
- **Media:** playing WAV, FLAC and MP3 files into a channel, and sharing computer audio or one program's sound, labelled for listeners and controlled by their own permission.
- **Moderation:** roles with ranks, per-channel permissions, warnings, mutes, kicks, bans, restrictions, reports, appeals, and a tamper-evident audit log; an Administration dialog.
- **Plugins and bots:** plugins as separate programs with consent for each permission; bot accounts; an SDK for bots in C++.
- **Hosting:** a server you can start from the app or run on its own (Windows, Linux, container), with automatic backups, restore, and a reachability check.
- **Security:** TLS 1.3 with trust on first use, Argon2id password hashing, remembered passwords only in Windows Credential Manager.
- **Accessibility:** every control has a name, live events are announced at a level you choose, nothing relies on sound or colour alone.

The full list is in the [changelog](https://github.com/donovanmalisch23-alt/opentalk/blob/v1.0.0-rc.1/CHANGELOG.md).

## Known limitations

- No message history on the server (by design: messages are not stored).
- Plugins are not sandboxed by the operating system and cannot play audio (bots can).
- On Windows 10, shared computer audio may carry some of other people's voices; send OpenTalk's sound to another device, or use Windows 11.
- Push-to-talk works globally only on Windows. Remembered passwords exist only on Windows.
- Linux and macOS desktops are not supported yet; the Linux server is.
