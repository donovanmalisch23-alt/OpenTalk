# Acceptance checklist: OpenTalk 1.0.0-rc.1

**Date:** 29 October 2026. Every requirement from the [project brief](../project-brief.md) and the [accessibility plan](../accessibility/plan.md), with its state and the evidence. Test names refer to programs in `tests/`; they run in CI on Windows and Linux.

**States:**

- **Met:** implemented and tested as described.
- **Met, not on hardware:** implemented and tested with simulated sound devices only.
- **Partly met:** some of it is missing; the gap is named.
- **Not verified:** needs a manual check that has not been done.

## Quality requirements

| ID | Requirement | State | Evidence, and gaps |
|---|---|---|---|
| N-LAT-1 | Mouth-to-ear at or below 150 ms on a LAN | Not verified | Budget from the design: about 85–130 ms ([benchmarks](../audio/benchmarks.md)). Not measured with real hardware. |
| N-AUD-1 | No audible dropouts at 5 % random loss | Met in simulation | Benchmarks: 0 % late packets, 0.4 % concealed. No listening test yet. |
| N-CPU-1 | Under 5 % of one core receiving 4 speakers | Met on the test machine | Opus decoding and mixing cost well under 1 % per speaker; all voice processing together about 4 % ([benchmarks](../audio/benchmarks.md)) |
| N-SCALE-1 | 100 users and 20 speakers on modest hardware | Met | `tst_tls_session` (150 clients); one core forwards voice for about 390 speakers to 50 listeners each ([benchmarks](../audio/benchmarks.md)) |
| N-UI-1 | The window never blocks on network, disk or audio | Met by design | Networking is asynchronous, audio runs on its own thread, settings files are small. No instrumentation measures freezes yet. |
| N-REL-1 | Settings and data survive crashes | Met | Atomic saves and backups before upgrades (`tst_settingsstore`, `tst_serverdatabase`) |
| N-MAINT-1 | Warnings as errors, formatting, one-way dependencies | Met | CI on every change |
| N-DOC-1 | Interfaces and settings documented with their state | Met | [Settings reference](../reference/client-settings.md), [protocol](../protocol/proposal.md), [SDK](../sdk/README.md), [status](../status.md) |

## Before 1.0.0 (final)

1. Run the NVDA test script on Windows 10 and 11, and fix what it finds (A-2, A-4 to A-7, A-11).
2. Try voice, files and computer audio with real devices and a second person; run `opentalk-audio-bench device-loopback` (N-LAT-1, N-AUD-1, F-VOICE-*, F-SYS-1).
3. Owner decisions: code signing, the plugin licensing review, the default branch and private vulnerability reporting.
